# BookFinder

BookFinder is a powerful and user-friendly tool designed especially for college students. It allows you to explore millions of books from the Open Library API with ease. With its advanced filter features, you can quickly search by title, author, year, or language, making your book discovery experience fast, precise, and enjoyable.

## Features

- Search books by title, author, year, or language.
- Explore millions of books from the Open Library API.
- Fast, precise, and user-friendly interface.
- Perfect for college students and avid readers.

## Technologies Used

- **React** – Frontend library
- **React Hooks** – State and effect management
- **CSS** – Styling
- **Bootstrap** – Responsive layout
- **Bootstrap Icons** – UI icons
- **Open Library API** – Book data source
